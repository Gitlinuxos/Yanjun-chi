# 旅行计划助手 (多智能体版) - Travel Assistant (Multi-Agent System)

基于 Qwen 最新大语言模型的多智能体协作旅行规划系统。通过多个具有特定角色的智能体（用户画像分析师、目的地推荐专家、交通规划师、行程编排师、预算精算师、气象顾问）协同工作，为用户提供高度个性化、动态且富有创意的旅行规划服务。

## 🌟 核心特性

- **多智能体架构**：6个专业智能体 + 1个协调者，分工协作
- **Qwen大模型驱动**：利用通义千问强大的理解与生成能力
- **动态上下文管理**：滑动窗口 + 语义摘要，防止上下文溢出
- **可靠工具调用**：工具网关模式 + 结构化输出 + 重试降级机制
- **状态机控制**：防死循环、防状态爆炸的DAG流程控制
- **自然语言交互**：支持模糊指令、多轮对话、动态调整

## 🏗️ 系统架构

```
用户输入
   ↓
[协调者 Agent] (Orchestrator)
   ├─ 意图识别 & 任务拆解
   ├─ 调度专业智能体
   └─ 汇总结果
      ↓
[专业智能体集群]
   ├─ 用户画像分析师 (Profile Agent)
   ├─ 目的地推荐专家 (Destination Agent)
   ├─ 交通规划师 (Transport Agent)
   ├─ 行程编排师 (Itinerary Agent)
   ├─ 预算精算师 (Budget Agent)
   └─ 气象顾问 (Weather Agent)
      ↓
[工具网关层] (Tool Gateway)
   ├─ 参数校验
   ├─ 执行重试
   ├─ 降级处理
   └─ 日志监控
      ↓
[共享黑板] (Shared State)
   └─ TravelPlanState (单一事实来源)
```

## 📋 功能模块

### 1. 用户信息管理 (Profile Agent)
- 从自然对话中提取结构化信息
- 动态更新用户画像（偏好、预算、时间、人数等）
- 支持模糊信息补全和确认

### 2. 智能目的地推荐 (Destination Agent)
- 基于用户偏好多维度匹配
- 动态生成推荐理由和亮点
- 支持多方案对比

### 3. 交通工具推荐 (Transport Agent)
- 多模态交通方案（飞机/高铁/自驾等）
- 智能比价与耗时估算
- 根据用户偏好（速度/舒适/经济）排序

### 4. 旅行计划生成 (Itinerary Agent)
- 自动生成每日详细行程
- 逻辑校验（时间冲突、路线合理性）
- 支持动态调整和备选方案

### 5. 预算管理 (Budget Agent)
- 费用拆解（交通/住宿/餐饮/门票等）
- 预算对齐与超支预警
- 智能节省建议

### 6. 天气监测 (Weather Agent)
- 旅行期间天气预报
- 极端天气预警
- 出行建议动态调整

### 7. 交互式确认与修改
- 支持自然语言修改指令
- 多轮迭代优化
- 版本管理与回滚

## 🛡️ 可靠性保障

### 工具调用安全
- **工具网关模式**：Agent 不直接调用工具，输出标准化请求由网关执行
- **结构化输出**：强制 JSON Schema 验证，防止格式错误
- **三级降级**：重试 (3 次) → 模拟数据 → 友好报错
- **超时控制**：单次调用超时 15 秒，防止阻塞

### 上下文管理
- **滑动窗口**：保留最近 5 轮完整对话
- **语义摘要**：早期对话自动压缩为关键信息
- **状态隔离**：每个会话独立状态，防止污染

### 流程控制
- **最大迭代次数**：单环节最多重试 3 次，防止死循环
- **状态机校验**：非法状态转换自动拦截
- **冲突检测**：多 Agent 修改冲突时自动协调

## 🔧 配置说明

### 环境变量
| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| DASHSCOPE_API_KEY | 通义千问 API 密钥 | 必填 |
| QWEN_MODEL | 使用的模型版本 | qwen-max |
| MAX_RETRY | 最大重试次数 | 3 |
| TIMEOUT | 单次调用超时 (秒) | 15 |

### 模型选择建议
- `qwen-max`: 复杂推理任务（推荐、行程规划）
- `qwen-turbo`: 简单提取任务（信息抽取、预算计算）
- `qwen-plus`: 平衡性能与成本

## 📝 开发指南

### 添加新智能体
1. 继承 `BaseAgent` 类
2. 实现 `process()` 方法
3. 在 `Orchestrator` 中注册
4. 编写专属 System Prompt

### 添加工具
1. 在 `tools/` 目录创建工具函数
2. 在 `gateway.py` 中注册工具元数据
3. 定义 JSON Schema 校验规则
4. 实现重试和降级逻辑

## ⚠️ 注意事项

1. **API 费用**：多轮对话会消耗较多 Token，请注意成本控制
2. **网络依赖**：需要稳定的网络连接访问 Dashscope API
3. **响应延迟**：复杂任务可能需要 10-30 秒处理时间
4. **数据隐私**：敏感信息请勿输入，生产环境需加密存储
