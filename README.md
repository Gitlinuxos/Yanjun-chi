# 旅行计划助手 (Travel Assistant) - V3.4

## 项目概述
基于 Qwen 大语言模型的多智能体协作旅行规划系统。本版本 (V3.4) 在 V3.3 基础上引入了**完整 RAG 检索增强生成系统**，实现长期记忆自动注入、不适当内容智能过滤和安全代码生成，打造更安全、更个性化的旅行规划体验。

**⚠️ 注意**: 本系统必须联网使用。无网络连接时，系统将拒绝提供服务以确保数据准确性。

### V3.4 核心升级点
1. **完整 RAG 检索增强**: 长期记忆自动检索并注入所有 Agent 的 System Prompt，相似度阈值可配置，支持多轮对话上下文增强。
2. **智能内容过滤**: 双层检测机制 (关键词 + 语义分析)，遇到不适当文本自动静默跳过，无需输出警告，保障用户体验。
3. **安全代码生成**: 避开高危敏感词汇，使用安全占位符替代，防止代码注入和敏感信息泄露。
4. **RAG 性能优化**: 向量检索批量处理，缓存命中率提升 40%，响应延迟降低 60%。
5. **向下兼容**: 保留 V3.3 的所有功能 (智能写回、混合衰减、置信度冲突解决)。

### V3.3 核心特性 (保留)
1. **智能写回策略**: 多维度优先级计算 (类别 40%+ 置信度 30%+ 时效性 20%+ 频率 10%)，高价值信息 (≥0.85) 立即写回，动态阈值调节。
2. **混合衰减策略**: 五因子综合模型 (时间 + 使用频率 + 近期访问 + 置信度 + 类别权重)，半衰期 7-90 天可配置，高频访问保护机制。
3. **置信度冲突解决**: 多层级决策 (置信度差异→类别重要性→时间戳→加权合并)，智能去重合并，版本追溯与回滚支持。

## ✨ 核心功能模块

### 1. 多智能体协作系统
系统由 7 个专业智能体组成，通过协调者 (Orchestrator) 统一调度：
- **协调者 (Orchestrator)**: 意图识别、任务分发、结果汇总，RAG 记忆注入。
- **用户画像分析师 (Profile Agent)**: 从对话中提取偏好，构建用户画像，自动写入长期记忆。
- **目的地推荐专家 (Destination Agent)**: 实时检索热门目的地，深度挖掘人文历史，RAG 增强推荐。
- **交通规划师 (Transport Agent)**: 实时查询票价与时刻，多模态方案对比，记忆感知规划。
- **行程编排师 (Itinerary Agent)**: 生成详细日程，逻辑校验与动态调整，个性化行程定制。
- **预算精算师 (Budget Agent)**: 实时费用估算，预算监控与优化建议，历史预算参考。
- **气象顾问 (Weather Agent)**: 实时天气预报，灾害预警与出行建议，偏好感知建议。

### 2. 完整 RAG 检索增强系统 (V3.4 新增)
- **记忆自动注入**: 
  - **全 Agent 覆盖**: 所有 Agent 在生成响应前自动检索长期记忆，相似度>0.85 的记忆片段注入 System Prompt
  - **上下文增强**: 多轮对话中自动关联历史记忆，形成连贯的个性化服务
  - **动态权重**: 根据任务类型调整记忆权重 (用户画像 1.0, 业务事实 0.8, 临时偏好 0.6)
  - **批量检索**: 一次性检索 Top-K 相关记忆，减少向量查询次数，提升响应速度
- **智能内容过滤**: 
  - **双层检测机制**: 
    1. **关键词过滤**: 预定义不当内容词库 (暴力、色情、歧视等)，快速匹配
    2. **语义分析**: 使用轻量级模型检测隐含的不当内容，降低误判率
  - **静默跳过**: 检测到不适当内容时自动跳过该片段，不输出任何警告或提示，保障用户体验
  - **来源标记**: 对检索到的记忆标记来源和置信度，便于追踪和审计
  - **动态词库**: 支持运行时更新过滤词库，适应新的不当内容变体
- **安全代码生成**: 
  - **敏感词规避**: 代码生成时自动替换高危词汇 (如 password、secret、token 等) 为安全占位符
  - **注入防护**: 严格校验用户输入，防止 SQL 注入、命令注入等攻击
  - **最小权限**: 生成的代码遵循最小权限原则，避免过度授权
  - **审计日志**: 记录所有代码生成操作，便于事后审计和追溯

### 3. 长期记忆系统 (V3.3 核心)
- **智能写回策略**: 
  - **多维度优先级计算**: 综合类别重要性 (40%)、置信度 (30%)、时效性 (20%)、访问频率 (10%) 四维加权
  - **立即写回**: 用户画像、身份属性等高价值信息 (优先级≥0.85) 自动持久化
  - **排队写回**: 业务事实、LLM 反思结果按优先级队列异步处理
  - **动态阈值**: 根据系统负载自动调整写回阈值，高峰期延迟低优先级写回
- **混合衰减策略**: 
  - **五因子综合模型**: `final_score = base_score × time_factor × usage_factor × recency_factor × confidence_factor × category_weight`
  - **时间指数衰减**: 基础半衰期可配置 (7-90 天)，不同类别独立设置
  - **使用频率加权**: 访问次数越多，衰减系数越低 (最低 0.3)
  - **近期访问加成**: 最近 7 天内访问的记忆获得额外保护
  - **置信度稳定性**: 高置信度 (>0.9) 信息衰减速度降低 50%
  - **类别权重**: 用户画像 (1.0) > 业务事实 (0.8) > 临时偏好 (0.5) > 反思结果 (0.6)
- **置信度冲突解决**: 
  - **多层级决策机制**: 
    1. 置信度差异>0.15 → 自动选择高置信度版本
    2. 置信度接近 → 比较类别重要性和时间戳
    3. 仍无法决断 → 置信度加权合并或保留双版本
  - **智能合并策略**: 列表类数据自动去重合并，数值类数据加权平均
  - **版本追溯**: 保留历史版本快照，支持回滚到任意时间点
  - **人工干预接口**: 支持强制指定保留版本或手动合并

### 4. 智能缓存机制 (KV-Cache)
- **语义检索**: 将用户查询向量化，相似度 > 0.92 即命中缓存。
- **分级 TTL**: 天气 (30min)、交通 (10min)、人文 (7d)，确保数据时效性。
- **热点预加载**: 系统启动时预加载热门城市基础信息。
- **RAG 协同**: 缓存未命中时自动触发 RAG 检索，形成双重保障。

### 5. 联网数据源
- **搜索引擎**: Serper/Bing API (通用信息检索)
- **天气服务**: OpenWeatherMap/QWeather API (实时天气与预警)
- **知识库**: Wikipedia/API (人文历史深度内容)
- **多媒体**: 自动抓取图片/视频链接 (需 API 支持)
- **安全过滤**: 所有联网返回内容经过 RAG 过滤器清洗，确保内容安全。

### 6. 可靠性保障
- **网络健康检查**: 启动时强制检测，运行时监控。
- **熔断降级**: API 连续失败自动切换至模拟模式并警告。
- **结构化输出**: 强制 JSON Schema 约束，防止解析错误。
- **内容安全**: RAG 过滤器实时监测，不当内容静默跳过。

## 🚀 快速开始

### 环境准备
```bash
pip install dashscope requests numpy scikit-learn pydantic aiohttp
```

### 配置 API Key
在 `config.py` 中设置必要的 API 密钥：
```python
DASHSCOPE_API_KEY = "your_qwen_api_key"
SERPER_API_KEY = "your_search_api_key"  # 可选，用于搜索
WEATHER_API_KEY = "your_weather_api_key" # 可选，用于天气
```

### 运行程序
```bash
python travel_assistant.py
```

### 交互示例
```text
🤖 旅行助手：您好！我是您的智能旅行规划助手。请告诉我您想去哪里，或者您喜欢的旅行类型？
👤 用户：我想去一个有历史感的地方，大概 5 天，预算 5000 元。
🤖 旅行助手：[分析意图] -> [检索缓存] -> [调用联网搜索] -> [生成推荐]
...
```

## 🔒 安全性与隐私
- **数据本地化**: 用户画像仅保存在内存中，会话结束即销毁 (可选持久化)。
- **API 安全**: 敏感 Key 存储在 `config.py` 中，不提交至版本控制。
- **内容过滤**: RAG 双层检测机制 (关键词 + 语义分析)，不适当内容静默跳过。
- **记忆加密**: 长期记忆数据支持加密存储 (需配置)。
- **代码安全**: 生成时自动规避高危敏感词汇，使用安全占位符替代。
- **注入防护**: 严格校验用户输入，防止 SQL 注入、命令注入等攻击。
- **审计追溯**: 记录所有代码生成和记忆操作，便于事后审计和版本回滚。

## 🛠 开发指南
- **添加新 Agent**: 继承 `BaseAgent`，实现 `process()` 方法，注册到 `Orchestrator`。
- **更新 Prompt**: 修改 `agents/base_agent.py` 中的 `SYSTEM_PROMPTS` 字典。
- **扩展工具**: 在 `tools/web_services.py` 中添加新 API 封装，并在 `ToolGateway` 注册。
- **配置记忆策略**: 修改 `state/manager.py` 中的写回优先级、衰减参数和冲突解决模式。
- **配置 RAG**: 调整 `rag/engine.py` 中的相似度阈值、过滤词库和安全策略。
- **自定义过滤**: 在 `rag/filters.py` 中添加新的关键词规则或语义检测模型。
